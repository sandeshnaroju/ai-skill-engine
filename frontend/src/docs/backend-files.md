# 🗄️ Files & Session Lifecycle

AI Skill Engine provides dedicated REST endpoints for uploading source documents, downloading tool-generated assets (charts, exported tables, compiled binaries), querying session files, and performing cascade purges.

---

## 📤 File Upload API

Upload user files (PDFs, Excel spreadsheets, images, CSVs, Word documents, CAD files) scoped to a conversation thread:

```
POST /api/v1/files/upload
```

### cURL Upload Example

```bash
curl -X POST http://localhost:8000/api/v1/files/upload \
  -H "Authorization: Bearer sk_mgr_YOUR_TENANT_API_KEY" \
  -F "file=@financial_report.xlsx" \
  -F "session_id=user_chat_thread_101" \
  -F "origin=external_api"
```

### JSON Response

```json
{
  "status": "success",
  "id": "file_uuid_94812",
  "filename": "uuid_financial_report.xlsx",
  "original_name": "financial_report.xlsx",
  "url": "/api/v1/files/download/tenant_prod/uuid_financial_report.xlsx",
  "session_id": "user_chat_thread_101",
  "size_bytes": 142080,
  "mime_type": "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
}
```

## 📥 File Download API

Download any file uploaded by a user or generated by sandboxed tools (e.g. Python matplotlib charts, CSV reports):

```
GET /api/v1/files/download/{tenant_name}/{filename}
```

*Note: In production deployments with Azure Blob Storage or AWS S3 configured, this endpoint returns a direct 302 redirect to an expiring presigned URL for maximum transfer throughput.*

---

## 🔍 Session Files Listing

List all active files associated with a given `session_id`:

```
GET /api/v1/files/session/{session_id}
```

### Optional Query Parameters

- `source`: Filter by origin (`upload` vs `tool_generated`)
- `origin`: Filter by metadata tag (e.g. `external_api`, `chat_playground`)

### cURL Example

```bash
curl -X GET "http://localhost:8000/api/v1/files/session/user_chat_thread_101?source=tool_generated" \
  -H "Authorization: Bearer sk_mgr_YOUR_TENANT_API_KEY"
```

---

## 🗑️ Single File Deletion

Permanently delete an individual file from cloud storage and remove its database metadata:

```bash
curl -X DELETE "http://localhost:8000/api/v1/files/file_uuid_94812" \
  -H "Authorization: Bearer sk_mgr_YOUR_TENANT_API_KEY"
```

---

## 🧹 Session Cascade Purge

When a user closes or deletes a chat conversation in your application, you can perform a cascade purge to instantly wipe all associated cloud files, database references, and artifact versions:

### Purge Files for a Session

```bash
curl -X DELETE "http://localhost:8000/api/v1/files/session/user_chat_thread_101" \
  -H "Authorization: Bearer sk_mgr_YOUR_TENANT_API_KEY"
```

### Purge Entire Session (Files + Messages + Artifacts)

```bash
curl -X DELETE "http://localhost:8000/api/v1/sessions/user_chat_thread_101" \
  -H "Authorization: Bearer sk_mgr_YOUR_TENANT_API_KEY"
```

> **💡 Best Practice:** Calling `DELETE /api/v1/sessions/{session_id}` automatically executes a transaction that removes Azure Blob / AWS S3 storage blobs, session files, artifacts, block commit diffs, and chat logs in a single call.
